El Desafío Actual

¿Por qué las organizaciones necesitan VeriThreat?

1. Inteligencia Fragmentada

Las empresas detectan amenazas (IPs, hashes, dominios) aisladamente sin mecanismos rápidos y seguros para compartirlos entre organizaciones socias.

2. Falta de Confianza en el Dato

Es complejo verificar la autenticidad, timestamp exacto y origen de los IOCs compartidos, corriendo el riesgo de inyectar datos falsos o duplicados.

3. Fatiga de Alertas en el SOC

El volumen masivo de alertas manuales sobrepasa la capacidad operativa de los analistas, ralentizando la respuesta ante ciberataques reales.

Propuesta de Valor

Una respuesta integral respaldada por tres pilares tecnológicos

Microservicios en Java

Ingesta asíncrona, normalización y distribución mediante Spring Boot y Apache Kafka.

Motor de IA & LLM Local

Scoring de riesgo automático con Scikit-Learn y síntesis de incidentes mediante Ollama (Llama 3).

Blockchain Permisionada

Hyperledger Fabric registra el hash e historia inmutable de cada amenaza auditada.

Cronograma del Proyecto

Las 6 Fases de Desarrollo

Metodología modular estimada para un ciclo de desarrollo de 14 a 16 semanas.

Fase 01 Semanas 1 - 2

Diseño y Modelado

Definición de arquitectura en 5 capas y estandarización del esquema del dato.

  • Modelo de datos estándar IOC (IPs, hashes, dominios).
  • Contratos de API REST/JSON inter-servicios.
  • Diagramas C4 de arquitectura.
Entregable: Especificación de Arquitectura
Fase 02 Semanas 3 - 4

Dataset & Motor IA

Preparación de datos abiertos y entrenamiento del modelo predictivo.

  • Ingesta OSINT (MISP, AlienVault, abuse.ch).
  • Modelo Scikit-learn para scoring de riesgo.
  • Integración LLM Ollama (Llama 3 local).
Entregable: Pipeline de IA Evaluado
Fase 03 Semanas 5 - 7

Backend Microservicios

Construcción del núcleo distribuido en Java para el procesamiento de datos.

  • Spring Boot 3 & Spring Cloud Gateway.
  • Persistencia PostgreSQL + Mensajería Kafka.
  • Orquestación completa con Docker Compose.
Entregable: Cluster de Microservicios Functional
Fase 04 Semanas 8 - 10

Red Blockchain

Red permisionada para auditoría e inmutabilidad descentralizada.

  • Despliegue Hyperledger Fabric (2-3 nodos).
  • Desarrollo Chaincode (Go/Java) para registro.
  • Conexión vía Fabric SDK para Java.
Entregable: Red Fabric & Chaincode Desplegados
Fase 05 Semanas 11 - 12

Frontend SOC & E2E

Interfaz web para analistas e integración completa de componentes.

  • Dashboard interactivo React + Tailwind CSS.
  • Visualización gráfica de alertas (Recharts).
  • Comprobador visual de validación en Blockchain.
Entregable: MVP Completo Operativo
Fase 06 Semanas 13 - 16

Validación & Memoria

Pruebas finales con feeds reales y preparación de la memoria técnica.

  • Pruebas de estrés y precisión del modelo IA.
  • Redacción de Memoria Técnica / Informe Corporativo.
  • Preparación de presentación ejecutiva.
Entregable: Memoria Académica & Defensa
